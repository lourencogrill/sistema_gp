# Roadmap do Lume People

Este documento descreve a direção futura do produto, funcionalidades planejadas e melhorias que estão no nosso radar.

## Próximos Passos (Curto Prazo)

Estas são as funcionalidades com maior prioridade e que planejamos desenvolver nos próximos ciclos.

-   **Q3 2025: Onboarding e Experiência do Usuário**
    -   [ ] **Tutorial Interativo:** Implementar um guia passo a passo para novas empresas (configuração, importação de colaboradores, criação de cargos).
    -   [ ] **Seeds Inteligentes:** Criar dados de exemplo realistas para demonstração (cargos, estruturas, avaliações).
    -   [ ] **Busca Global (Ctrl+K):** Implementar busca inteligente por colaboradores, cargos e habilidades.
    -   [ ] **Melhorias de UX/UI:** Adicionar skeleton screens, toasts de notificação e responsividade completa.

-   **Q4 2025: Engajamento e Comunicação**
    -   [ ] **Sistema de Notificações Push:** Implementar notificações para gestores (avaliações pendentes) e colaboradores (autoavaliação).
    -   [ ] **Módulo de Feedback Contínuo:** Reintroduzir o módulo de feedback (positivo, sugestão) integrado às avaliações.
    -   [ ] **Plano de Desenvolvimento Individual (PDI):** Conectar os resultados das avaliações a um PDI acionável.
    -   [ ] **Dashboard Pessoal do Colaborador:** Uma visão para o colaborador com seus resultados, feedbacks e PDI.

## Visão de Longo Prazo

Funcionalidades que fazem parte da visão estratégica do Lume People, sem uma data definida.

-   **Gestão de Metas (OKRs):**
    -   Módulo completo para definir e acompanhar Objetivos e Resultados-Chave.
    -   Conectar OKRs com as avaliações de desempenho.

-   **Pesquisas e Clima Organizacional:**
    -   Reintroduzir o check-in de clima com dashboards avançados.
    -   Módulo para criação de pesquisas customizadas (eNPS, pesquisas de engajamento).

-   **Recrutamento e Seleção (ATS):**
    -   Funil de recrutamento integrado aos cargos já existentes.
    -   Portal de carreiras para candidatos.

-   **Integrações:**
    -   Integração com Slack e Microsoft Teams para notificações.
    -   APIs para conexão com sistemas de folha de pagamento.
    -   Login único (SSO) com provedores corporativos.

-   **Inteligência Artificial:**
    -   Análise preditiva de turnover e burnout.
    -   Sugestões de desenvolvimento baseadas em IA.
    -   Assistente de IA para ajudar a escrever descrições de cargo e feedbacks.

## Como Solicitar Novas Funcionalidades

O feedback dos usuários é crucial para a evolução do Lume People. Para sugerir uma nova funcionalidade ou melhoria, por favor, abra uma "Issue" no nosso repositório do GitHub com o label `feature-request`.
